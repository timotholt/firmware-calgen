# Plan: magnetics demo (initiative 1) — approved 2026-10-17, built

## Goal
Show, concretely and honestly, the first step toward AMETEK's magnetics initiative: turning past inductor and transformer drawings into **structured, physics-checked, searchable data**. Not an AI that designs magnetics. Same pattern as calgen: deterministic where correctness matters, AI only where inputs are messy, a person approves.

## What the reviewer sees (new "Magnetics" tab on the existing site)
1. A table of ~12 synthetic component drawings, each with its extracted fields and a gate verdict (pass / flagged, with the reason).
2. Click a row: the drawing image, the extracted fields (each with where it came from), and the checks typeset as math, e.g. L = A_L · N² = 160 nH × 56² = 502 µH vs stated 500 µH ✓.
3. A search panel: filter by inductance range, current, core material/family, plus "find similar designs" ranked by closeness.
All of it runs in the browser (Pyodide), like the playground. No keys, no network.

## Data (honesty rules)
- **Core catalog: real, public.** ~10 cores from vendor data sheets (e.g., Magnetics Inc., TDK/EPCOS, Ferroxcube): part number, material, A_L (nH/turn²) and its tolerance, effective area A_e, path length l_e, window area W_a, saturation flux B_sat. Each value cited to its data sheet page, transcribed (not redistributed PDFs).
- **Drawings: synthetic, labeled as such.** Generated by a script into PDFs that look like typical custom-magnetics drawings: title block, winding table (pins, turns, wire gauge), electrical test table (L at test frequency, DC resistance, high-voltage test). No AMETEK or other company data.
- **Seeded problems** (with a blind answer key, like the legacy corpus): a turns typo (L mismatch), µH/mH unit slip, wire too thin for the current, too much copper for the bobbin window, peak current that saturates the core, a core part number not in the catalog.

## Pipeline
1. **Extract** from the PDF text layer into a schema (deterministic parser). Every field keeps its source location. Scanned drawings and an LLM/vision path are listed as future work in v1 (see open question 2).
2. **Check** with physics, reusing calgen's unit-checked formula engine and typeset derivations:
   - Inductance: L ≈ A_L · N², within the core's A_L tolerance.
   - Saturation: B_pk = L · I_pk / (N · A_e) below B_sat × margin.
   - Current density: I_rms / wire area ≤ a stated design limit (an assumption, labeled).
   - Window fill: N × wire area / W_a ≤ a stated fill factor (assumption, labeled).
   - Core part number exists in the catalog.
   Failing records go to a review list with the reason, never silently into the dataset.
3. **Search:** structured filters over the checked records, plus a simple similarity ranking on normalized L, current, frequency, and core size.

## Tests
Parser round-trips every generated drawing; each seeded problem is caught by the expected check and nothing else is flagged (answer key); search returns the expected designs; typeset math equals computed values (existing pattern).

## Limits stated on the page
Synthetic drawings; textbook first-order physics (no core-loss or thermal model in v1); design limits are assumptions; real drawings are messier, so the first real step would be sampling ~10 of theirs to fix the schema.

## Effort and cost
About a day. No paid model calls in v1. New dependencies: a PDF writer for the generator and a PDF text extractor (both pure-Python, pinned).

## Phase 2 plan: "Size an inductor" and the playground link (approved 2026-10-17)

**Goal:** turn the tab from a gallery into the workflow the initiative describes: requirement → candidate designs from real cores, checked → closest past designs. Deterministic physics only; ML would later correct it against bench measurements.

**Sizing engine (Python, `calgen.magnetics.size_inductor`, runs in the browser via Pyodide):**
- Inputs: required inductance *at peak current*, RMS current, peak current, switching frequency, minimum inductance retained at peak (80% conservative, 50% common for PFC; user picks).
- Cores: the Kool Mµ toroids in the catalog, stacked 1–3 high (A_L, A_e, V_e scale with the stack; l_e and window don't). Two larger real cores are added (0077110A7, 0077908A7), cited like the rest. Ferrite E cores are excluded: they need a gap for inductors and the catalog holds ungapped A_L only.
- Inductance at peak current: A_L·N² times the fraction of permeability left at the peak magnetizing force, linearly interpolated between the data sheet's points (0 → 100%, H₈₀ → 80%, H₅₀ → 50%); the real curve sits above these lines at low bias, so this is conservative. Beyond H₅₀ the core is rejected (no extrapolation).
- For each core and stack: smallest turns meeting the inductance; smallest copper (AWG 10–24, 1–6 strands) meeting the current-density limit; then window fill. Passing candidates are ranked by core volume, then copper; failures show their first reason.
- Closest past designs: the existing records ranked by inductance and current.

**Playground link (requirements are first-pass estimates, labeled as such):**
- Rectifier stage → PFC boost inductor: RMS current = data sheet max input current; ripple = 30% of the line peak (assumption); L = V_bus / (4·f_sw·ΔI) (boost, worst case at V_in = V_bus/2); peak = line peak + ΔI/2.
- AC output stage → output filter inductor: RMS current = the overload trip level; peak = the hardware peak-current limit (the inductor must not collapse before the comparator trips); ripple = 30% of rated peak (assumption); L = V_bus / (4·f_sw·ΔI) (unipolar full bridge, worst case).
- Each stage shows the estimate and a "size it →" link that opens the Magnetics sizing panel pre-filled.

**Tests:** every returned candidate re-checked independently against the limits; interpolation matches data sheet points; known requirement → known best core; requirement estimates for FA10507 match hand-worked numbers; KaTeX parse of the new math.

**Navigation:** Overview · Firmware playground · Magnetics · Audit · Review reports · How it works · AI practice · Tim Otholt (done first).

## Phase 3: vendor DC-bias curves; transformer drawing fixes (2026-10-17)
- **Source:** Magnetics *Powder Cores* catalog, 2025, p. 63, "Permeability versus DC Bias Curves — Fit Formula", Kool Mµ Toroids: % initial permeability = 1 / (a + b·H^c), H in oersteds. Coefficients for 26µ, 60µ, 125µ go in `specs/magnetics/dc_bias_fit.csv`, cited.
- **Consistency:** the fit is the vendor's *typical* curve; the per-part data sheets give *minimum* bias at 80% and 50%. For 60µ the fit reaches 80% at ~45 Oe vs the 39 Oe minimum (~15% optimistic). Same shape, different promise.
- **Model used for checks and sizing ("derated fit"):** the vendor curve with H scaled by k = max(H_fit,80/H_min,80, H_fit,50/H_min,50), so it passes at or below both guaranteed minimum points: smooth, vendor-shaped, and still conservative. No extrapolation past the data sheet's 50% point. The existing record check (peak H ≤ H₈₀ minimum) is unchanged.
- **Charts:** derated curve solid, vendor typical curve faint, the two guaranteed points marked; x-axis 0 to 1.5× the design's peak current so the operating point's margin is visible.
- **Transformers:** windings drawn as layers (columns along the window height), primary nearest the center leg, insulation gap, then secondary; shown at normal size since transformers have no inductance curve. Number formatting no longer uses scientific notation.

## Phase 4: transformer construction (bobbin, margins, insulation) (2026-10-17)
**Why:** the transformer window check compared bare copper with the bare core window against a 25% proxy limit, and the picture showed windings touching the core with no safety insulation, though the drawings call for a 3000 VAC primary-to-secondary test.

**Model (assumptions, stated in `limits.yaml` and on the page; real values come from the applicable safety standard, working voltage, and the bobbin's data sheet):**
- Coil former (bobbin): 1.0 mm wall on the center-leg side and at both flanges.
- Margin tape: 3.0 mm at each end of the winding breadth, so creepage between primary and secondary runs around the margins (typical for reinforced insulation at this test voltage).
- Tape: 3 layers × 0.05 mm between windings; 2 layers over the outside.
- Winding: turns per layer = usable breadth / wire diameter (heavy-build enamel, ≈1.08 × bare); layers stack outward from the bobbin; primary first.

**Check:** `window_fill` for E cores becomes a build check: bobbin wall + all layers + tape ≤ window width (bare (B − C)/2 from the core data). Message gives used vs available mm. Toroids keep the bare-copper fill check (no bobbin).
**Drawing:** window with bobbin, margin tape blocks, tape lines between windings, and conductors in their layers, to scale.
**Answer key:** unchanged (both transformers still fit; XFMR-002 is flagged only for its turns ratio).
